## 🌟 Key Features

### 1. 🌅 05:00 AM POTD Vault & Sequential Homework Engine
* **Automatic 05:00:00 AM Morning Unlocks**: The daily algorithmic challenge opens exactly at 05:00:00 AM sharp.
* **Sequential Progression Locks**: Homework problems unlock in strict pedagogical sequence ($HW_1 \rightarrow HW_2 \rightarrow HW_3$).
* **Weekend Rush Quota**: Automatically assigns $+2$ bonus homework challenges on Saturdays and Sundays.

### 2. 🐙 Direct GitHub Commit Engine
* Seamless client-side Git integration using GitHub's REST API.
* Every verified solution solved in the browser is directly committed and pushed to your personal GitHub repository with authentic commit messages, execution stats, and contribution squares.

### 3. 💻 In-Browser VS Code IDE with Pyodide CPython 3.12 WebAssembly
* Full CPython 3.12 execution running $100\%$ client-side in the browser via WebAssembly (`pyodide.js`).
* Multi-language support: Python, JavaScript/TypeScript, SQL, and HTML/CSS.
* Real-time automated test runner with sample and hidden test case verification.

### 4. ⚔️ 1v1 Live Code Duel Arena & Bug Hunt
* Real-time 180s live coding battle against **Bugsy the Glitch**.
* Dual 100 HP health bars, live simulated typing, combat power-ups (*Syntax Shield*, *Overclock*, *Time Warp*).
* Exterminate 5 critical production bugs in the Bug Hunt Arena.

### 5. 💼 FAANG Mock Technical Interview Simulation
* Realistic 45-minute live interview environment covering Google, Meta, Amazon, and OpenAI tracks.
* 4-Stage structure: Scoping & Clarification $\rightarrow$ Approach Discussion $\rightarrow$ VS Code Implementation $\rightarrow$ Official Evaluation Scorecard (*Strong Hire* grading).

### 6. 🧠 RAM Stack vs. Heap Pointer Sandbox
* Real-time visualization of CPython and systems memory architecture.
* Traces Stack frames (`0x7FFE...`), function call depth, local variables, and Heap dynamic buffers (`0x00A0...`).
* Step-by-step simulations: Dynamic Array Geometric Doubling, Linked List In-Place Reversal, and Recursive Call Stack Depth.

### 7. 🎓 CS 201 Accredited 10-Module Academic Syllabus
* Built in alignment with university standards (CLRS, MIT 6.006, Bloom’s Taxonomy).
* 10 Standard Modules: Asymptotic Analysis, Hash Tables, Two Pointers, Monotonic Stacks, Binary Search, Heaps, Graphs, Dynamic Programming, Relational SQL, and Linear Algebra Vectors for AI.
* Integrated 50/10 Pomodoro Study Block Timer with focus audio alerts.

### 8. 📊 Real-Time Engine, Big-O Profiler & Lo-Fi Synthesizer
* **Live Telemetry & Heartbeat**: High-frequency 1-second pulse, ping jitter (11–19ms), active coding focus stopwatch, and APM tracker.
* **Big-O Benchmark Studio**: Benchmark algorithm speed across scaling inputs $N = 10 \dots 100,000$ with live SVG execution time curves.
* **Lo-Fi Procedural Synthesizer**: In-browser procedural music generator using the Web Audio API with 4 ambient modes (*Lo-Fi*, *Chiptune*, *Cyberpunk*, *Rain*).

* **Core Framework**: React 18, TypeScript, Vite 8

* **Audio Synthesis**: Web Audio API (procedural frequency oscillators, noise filters)
* **APIs**: GitHub REST API, Codeforces Public API, Google Gemini AI API

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/siddhantthakur278-bit/algorithm-adventures-dsa.git
cd algorithm-adventures-dsa

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
