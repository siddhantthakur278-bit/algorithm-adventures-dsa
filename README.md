## 🌟 Key Features & Architecture

### 1. ⌨️ Universal Command Palette (`⌘K` / `Ctrl+K`)
* **Instant Keyboard Access**: Open anytime using `⌘K` (Mac) / `Ctrl+K` (Windows/Linux) or the navbar pill.
* **Fuzzy Navigation**: Jump across all 18 tabs, 6 comic sagas, and 6 high-tech research labs with zero clicks.
* **Instant Execution**: Switch themes, toggle Web Audio synthesizer modes, trigger benchmarks, and sync Git commits.

### 2. 🎨 Universal Theme Accent Engine
* **5 Customizable Cybernetic Presets**:
  * ⚡ **Cyberpunk Neon** (`#06B6D4` & `#38BDF8`)
  * 🌟 **Golden Manga** (`#FBBF24` & `#FB923C` — ADA Classic)
  * 💻 **Matrix Terminal** (`#10B981` & `#34D399`)
  * 🌌 **Tokyo Midnight** (`#8B5CF6` & `#A78BFA`)
  * 🩸 **Synthetix Rose** (`#F43F5E` & `#FB7185`)
* Persistent `localStorage` settings and dynamic CSS root custom properties.

### 3. 🔬 High-Tech Cybernetics & Systems Research Lab
Six interactive deep-engineering simulators running $100\%$ client-side:
* **CPython 3.12 Bytecode Disassembler**: Step-through stack machine opcodes (`LOAD_GLOBAL`, `BUILD_SET`, `CONTAINS_OP`) comparing $O(N)$ linear scans with $O(1)$ set probes.
* **Neural Code Vector Space**: 2D PCA projection scatter visualizing semantic code embeddings, clustering optimal hash map, two-pointer, and brute force solutions.
* **Distributed Raft Consensus Simulator**: 5-node cluster with leader heartbeats, candidate elections, and network partition split-brain quorums ($> 50\%$).
* **Universal AST Explorer & Wasm JIT Studio**: Interactive syntax tree hierarchy with lexical tokens, WebAssembly Text (**WAT**) emission, and operand stack step-through.
* **Quantum Circuit & Qubit Superposition Lab**: 2-qubit register with Hadamard ($H$), Pauli-X, Pauli-Z, and Measurement gates, entangled Bell state generation, Grover's $O(\sqrt{N})$ search speedup, and 3D Bloch sphere vector projection.
* **Distributed Rate Limiter Lab**: Token Bucket, Leaky Bucket, and Sliding Window simulations with live burst/DDoS traffic generator and production atomic Redis Lua script dossier.

### 4. 🎙️ Web Speech AI Voice Pair-Programming Cockpit
* **Real Voice Commentary**: Professor Algorismus 🧙‍♂️ and Byte 🤖 speak algorithm explanations and debugging hints aloud using the Web Speech API.
* **Live AST Code Metrics**: Real-time Cyclomatic Complexity ($M$), Big-O Upper Bound estimation, Maintainability Index, and code smell detector.

### 5. 🌅 05:00 AM POTD Vault & Sequential Homework Engine
* **Automatic 05:00:00 AM Morning Unlocks**: The daily algorithmic challenge opens exactly at 05:00:00 AM sharp.
* **Sequential Progression Locks**: Homework problems unlock in strict pedagogical sequence ($HW_1 \rightarrow HW_2 \rightarrow HW_3$).
* **Weekend Rush Quota**: Automatically assigns $+2$ bonus homework challenges on Saturdays and Sundays.

### 6. 🐙 Direct GitHub Commit Engine
* Direct client-side Git synchronization using GitHub's REST API.
* Every verified solution solved in the browser is committed directly to your repository with authentic commit hashes, execution stats, and contribution squares.

### 7. 💻 In-Browser VS Code IDE with Pyodide CPython 3.12 WebAssembly
* Full CPython 3.12 runtime running $100\%$ client-side in the browser via WebAssembly (`pyodide.js`).
* Multi-language support: Python, JavaScript/TypeScript, SQL, and HTML/CSS.
* Real-time automated test runner with sample and hidden test case verification.

### 8. ⚔️ 1v1 Live Code Duel Arena & Bug Hunt
* Real-time 180s live coding battle against **Bugsy the Glitch**.
* Dual 100 HP health bars, live simulated typing, combat power-ups (*Syntax Shield*, *Overclock*, *Time Warp*).
* Exterminate 5 critical production bugs in the Bug Hunt Arena.

### 9. 💼 FAANG Mock Technical Interview Simulation
* Realistic 45-minute live interview environment covering Google, Meta, Amazon, and OpenAI tracks.
* 4-Stage structure: Scoping & Clarification $\rightarrow$ Approach Discussion $\rightarrow$ VS Code Implementation $\rightarrow$ Official Evaluation Scorecard (*Strong Hire* grading).

### 10. 🧠 RAM Stack vs. Heap Pointer Sandbox
* Real-time visualization of CPython and systems memory architecture.
* Traces Stack frames (`0x7FFE...`), function call depth, local variables, and Heap dynamic buffers (`0x00A0...`).
* Step-by-step simulations: Dynamic Array Geometric Doubling, Linked List In-Place Reversal, and Recursive Call Stack Depth.

### 11. 🎓 CS 201 Accredited 10-Module Academic Syllabus
* Built in alignment with university standards (CLRS, MIT 6.006, Bloom’s Taxonomy).
* 10 Standard Modules: Asymptotic Analysis, Hash Tables, Two Pointers, Monotonic Stacks, Binary Search, Heaps, Graphs, Dynamic Programming, Relational SQL, and Linear Algebra Vectors for AI.
* Integrated 50/10 Pomodoro Study Block Timer with focus audio alerts.

### 12. ⚡ Performance Optimizations
* **71.3% Bundle Reduction**: Dynamic `React.lazy()` route splitting dropped initial bundle from `2.07 MB` down to `593 kB`.
* **In-Memory LRU Test Caching**: Repeated test runs execute in `0 ms` using input-hash memoization.
* **60 FPS GPU-Accelerated Audio Visualizer**: Web Audio frequency spectrum canvas running on `requestAnimationFrame` with zero CPU idle draw.

* **Core Framework**: React 18 / 19, TypeScript, Vite 8 (Rolldown engine)

* **Compiler Runtimes**: Pyodide (CPython 3.12 WebAssembly), Alasql (In-Memory SQL)
* **Audio Synthesis**: Web Audio API (procedural oscillators, frequency analysers, noise filters)
* **Voice Speech**: Web Speech Synthesis API
* **APIs**: GitHub REST API, Codeforces Public API, Google Gemini AI API

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/siddhantthakur278-bit/algorithm-adventures-dsa.git
cd algorithm-adventures-dsa

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production (verified clean build in < 350ms)
npm run build
```
